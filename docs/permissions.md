## 帳號

- **擁有者主帳號**：PIN 存在 Script Properties 的 `OWNER_PIN`，不在程式碼或資料中。忘記時到 Apps Script 專案設定直接修改。
- **個人帳號**：由擁有者在系統內建立，每位壇務一組 PIN（4–8 位數字）。流水帳會記錄是誰操作的。
  - PIN 以加鹽雜湊儲存在 Script Properties 的 `USERS`（帳號多時分段存放），不是明文。
  - 也可以建立第二位擁有者（例如副負責人）。
  - 停用或刪除帳號後，該帳號原本的登入會立即失效。
- **登入保護**：同一帳號 PIN 錯 5 次，鎖定 15 分鐘。登入 6 小時內有效，使用中自動延長。

## 刪除的安全網

- 刪除一律先進回收區，擁有者可以還原。
- 跨年度結算與匯入資料前，後端會自動在試算表留一份備份（隱藏的 `_backup_日期時間` 工作表）。
